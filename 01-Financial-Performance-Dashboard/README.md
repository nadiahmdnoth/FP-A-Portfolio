# Project 01 — Financial Performance Dashboard

## Overview
An Excel FP&A case study demonstrating monthly financial performance monitoring, budget-versus-actual variance analysis, forecasting and executive reporting.

**Data:** Entirely fictional FY2026 monthly data in Malaysian ringgit (RM). No confidential information is included.

## Key analyses
- Revenue: actual vs budget and forecast, including RM and percentage variances
- Cost: budget less actual, where a positive variance indicates savings
- Gross profit: revenue less modelled costs
- Gross profit margin: gross profit / actual revenue
- Executive-level management commentary and 12-month revenue trends

## Workbook structure
1. **Executive Dashboard** — summary KPIs, trend chart and commentary
2. **Monthly Performance** — linked formulas and annual totals
3. **Fictional Inputs** — editable assumptions and data
4. **Read Me** — model glossary and use instructions

## How to use
1. Download `FPnA_Financial_Performance_Dashboard_FY2026.xlsx`.
2. Open it in Microsoft Excel.
3. Review the Executive Dashboard.
4. Change the blue input figures in Fictional Inputs to test the calculations.
5. Review Month Performance and return to the dashboard for management insights.

## Model caveat
The **EBITDA proxy** equals gross profit because this simplified illustrative model does not separately model indirect operating expenses, depreciation or amortization. It is not a complete IFRS EBITDA reconciliation.
